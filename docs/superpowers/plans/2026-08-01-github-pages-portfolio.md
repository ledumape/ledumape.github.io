# GitHub Pages Portfolio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the existing public portfolio at `https://ledumape.github.io` without requiring any visitor sign-in.

**Architecture:** Keep the current React portfolio as the source of truth, add a static-export build mode for GitHub Pages, and publish the generated static directory through a GitHub Actions workflow. Keep the existing public Sites deployment unchanged as a fallback until the GitHub Pages URL is verified.

**Tech Stack:** Next.js 16, vinext/Vite static export, GitHub Actions, GitHub Pages.

## Global Constraints

- The public site must expose only the existing email, LinkedIn, GitHub, and project links.
- Do not commit keys, local configuration, build artifacts, or temporary archives.
- The GitHub Pages site must be public and work at `https://ledumape.github.io`.
- Keep the current Sites URL online until GitHub Pages has a verified successful deployment.

### Task 2: Publish static output with GitHub Actions

**Files:**
- Create: `.github/workflows/deploy-pages.yml`
- Modify: `tests/github-pages-export.test.mjs`

**Interfaces:**
- Consumes: the static directory generated by `npm run build:pages`.
- Produces: a push-to-main workflow using GitHub's Pages artifact and deployment actions.

- [ ] **Step 1: Extend the failing test**

```js
const workflow = await readFile(new URL("../.github/workflows/deploy-pages.yml", import.meta.url), "utf8");
assert.match(workflow, /actions\/upload-pages-artifact/);
assert.match(workflow, /actions\/deploy-pages/);
assert.match(workflow, /path:\s*\.\/dist\/client/);
```

- [ ] **Step 2: Run test to verify it fails**

Run: `node --test tests/github-pages-export.test.mjs`

Expected: FAIL because the workflow file does not exist.

- [ ] **Step 3: Add the workflow**

```yaml
name: Deploy GitHub Pages
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
      - run: npm ci
      - run: npm run build:pages
      - uses: actions/upload-pages-artifact@v3
        with:
          path: ./dist/client
      - id: deployment
        uses: actions/deploy-pages@v4
```

- [ ] **Step 4: Run tests and lint**

Run: `npm.cmd test; npm.cmd run lint`

Expected: PASS with every test green and no lint errors.

- [ ] **Step 5: Commit**

```powershell
git add .github/workflows/deploy-pages.yml tests/github-pages-export.test.mjs
git commit -m "Deploy portfolio with GitHub Pages"
```
